## 4. MVP 验证决策树

```
MVP-1 + MVP-2 执行
    │
    ├── 模型主动使用 ctx_recall?
    │   ├── YES → 信息恢复有效
    │   │    ├── 重读减少 ≥50%?
    │   │    │   ├── YES → ✅ 锚充分性验证通过
    │   │    │   │         → 继续Spec A-E(完整编排器)
    │   │    │   └── NO  → 🟡 部分通过
    │   │    │         → 调整工具描述/prompt → 重测
    │   │    └── 死循环被打破?
    │   │        ├── YES → ✅ 防死循环场景验证
    │   │        └── NO  → P5 Escalate 优先级提升
    │   │
    │   └── NO → 模型不使用工具
    │        ├── 工具描述不够醒目 → 改描述 → 重测
    │        └── 模型能力不足(9B/35B 不会用新工具)
    │             → 加 system prompt 提示 → 重测
    │             → 仍不行 → 需要训练(Spec-E 后)
    │
    └── 检索结果不正确?
         ├── manifest 覆盖率问题 → 检查 hooks
         └── FTS5 检索质量问题 → 调整 tokenizer
```
