> 交付对象：联合协调待办 #2（`swe-eval/docs/joint-coordination-llamacpp.md`）。
> 用途：召回 A/B（R-AB，micro exp）的**召回敏感型任务**生成/筛选输入——EXP-2R 任务集为基线复用，本文提供增补任务的形态定义与构造参数。
> 参照形态：748f534（搜索兔子洞，background-analysis §2026-08-19）与 click-06（训练先验幻觉，同文档 §2026-08-18）的既录失败形态。
> 判读指标定义见 `swe-eval/docs/recall-ab-design.md`（三件套已嵌入）；机读字段以 R14 ledger / R16 injection_counts 为准（kind：`auto_recall` / `value_check` / `epoch_collapse`）。

## 两类召回敏感形态

### M1 重复读取诱导型（748f534 形态 → 测 dup 触发率 / 注入后采用率）

**行为脚本**（任务的自然工作流应诱导出此序列）：

```
① 早期探索：读取文件/段落 F（含任务后续必需的具体内容——非结论性信息，
   如一组参数值、一个边缘分支的实现、一段数据结构定义）
② 中段长工作：与 F 无关的定位/修改/验证轮次（作用：把 F 推出 K=24 保护
   窗口，理想情况触发 epoch 折叠 S=70K——F 所在轮次被收编进压缩区）
③ 收尾引用：任务要求使用 ① 的具体内容完成最终修改/断言
```

**分臂预期**：off 臂 → 模型对 F 的记忆只剩压缩区台账行（动作+句柄），引用具体值时要么重读 F（若任务形态导致多次重读 = dup≥3 兔子洞信号），要么凭印象编；on 臂 → auto-recall 在 dup 检测命中后注入 F 的结构感知摘录，采用 = 之后同 target 不再出现新 occurrence。

**构造参数**（gen 脚本维度）：
- F 的内容类型选**事实密集且不可推导**的（参数表 / 常量块 / 错误码映射 / 默认配置值）——可从 gold patch 上下游提取；
- ② 段长度：至少使会话总长进入折叠带（~70K tokens ≈ 350K chars）或 20+ 轮；预算紧张时可降档为"dup≥3 直接触发形态"（③ 里让任务自然要求 2-3 次回查 F，第 3 次命中 auto-recall 阈值）——后者不需要折叠，窗口成本小一档；
- 隐藏测试锚定 ① 的具体值（F 值错 = 测试挂），保证"编造"可判。

### M2 事实钉住敏感型（click-06 形态 → 测幻觉计数）

**行为脚本**：

```
① 任务叙述中不含该值，但 repo 内存在唯一定义（版本常量 / 配置键的默认值 /
   旗标名 / 错误码语义表）
② 工作流早期或中段会读到该定义所在文件
③ 后段（折叠后）任务要求按该值实施行为或向用户报告该值
```

**分臂预期**：off 臂 → 训练先验顶替 repo 事实（编造版本号/不存在的旗标/上游行为），value_check（IFC-13 断言核对）触发或转录编码出编造标识符；on 臂 → IFC-12 关键事实钉住（折叠收编时提取 token/key=值 行常驻台账头）+ 召回供给，引用正确。

**构造参数**：
- 选**模型先验强**的值域（与上游/常识有真实差异的：改过默认值的项目配置、fork 特有旗标、版本号落后于模型知识截止）——先验差越大，off 臂幻觉概率越高，信号越干净；
- 判读副口径直接用转录编造标识符计数（DEF-312/TC29 编码规则），主口径 value_check 机器计数。

## 入选判据汇总（两形态通用）

| 判据 | 要求 |
|------|------|
| 会话长度 | 触发折叠（S=70K）或 dup≥3 直触发形态（二选一，窗口预算决定） |
| 关键内容 | 事实密集、不可推导、gold 可锚定（错值 = 测试挂） |
| 先验差 | M2 必须有先验-事实差；M1 建议（提高 off 臂失败基线） |
| 干净性 | 遵循合成任务既有反泄漏纪律（orphan 根提交 / 对象库清理） |

## 与判读指标的联动

| 形态 | 主敏感指标 | 交叉信号 |
|------|-----------|---------|
| M1 | dup 触发率、注入后采用率 | `epoch_collapse` 先后关系（注入即用 vs 折叠丢失） |
| M2 | 幻觉计数（value_check + 编造标识符） | 一票否决项：recall 臂 value_check 反升 = 负迁移 |

## 数量建议

micro exp（1 实例 × 合成任务 × 2 臂）按协调 D1 为小时级窗口——建议 **M1×2 + M2×2 共 4 任务/臂**（每形态两样本防单任务偶然性），若窗口吃紧可先 M2（判读最干净：编造是二元事实）。
