# 监控自动重启能力升级（2026-10-27）——「昨天那情况能否避免」的结论与落地

> 触发问题：2026-10-26 批跑收官后服务带残留劣化空转近 2 小时、swap 涨到 10.4GB，
> 监控守护的 AUTO_RESTART 为何没兜住？升级后能兜什么、不能兜什么。

## 1. 事实回溯（先查再改）

| 事实 | 证据 |
|------|------|
| **AUTO_RESTART 从未触发过** | 全量日志 grep「自动重启」零命中；守护启动行恒为 `自动重启=0`（`MONITOR_AUTO_RESTART` 从未置 1） |
| 批跑收官后劣化残留 2h 无人处理 | `03:04` 与 `04:04` 两轮快照一致：`mem 22.56G head 17.7G denied 765 ttft p95 9.8s dec 72.5`；`05:04` 引擎 idle-release 才把内存放掉（mem 1.43G / head 38.83G） |
| swap 一路涨到 10.4GB | 重启前实测 `total 11264M used 10444M`（动态 swap 近满） |
| 旧判据只有一条 | `memory_denied>500 且 batch=False` → 一旦累计超阈**永远为真**（累计量不回落），既不能区分「历史累积」与「现在还坏着」，也无法防止反复触发 |
| 无冷却/退避 | 命中即 `./manage.sh restart`，**每 5 分钟可再触发一次**；重启失败（swap 近满 → DEF-320 bootstrap 失败）⇒ 重启风暴，比不重启更糟 |

## 2. 结论：AUTO_RESTART 能兜什么、不能兜什么

| 昨天那次的成因 | AUTO_RESTART（升级后）能否避免 | 机制 |
|----------------|------------------------------|------|
| 批跑把引擎 KV/state 撑大（denied 累积 765、TTFT p95 9.8s、decode 72.5） | **能**（清场判据 A） | 批跑收官一次性重启：清 KV/state、denied 归零、headroom 回位 |
| 收官后残留劣化空转 2 小时 | **能**（清场判据 A 命中即清） | 同上（昨天 03:04 那一轮即可触发） |
| **swap 膨胀到 10.4GB（系统级内存耗尽）** | **不能** | 引擎重启释放的是引擎内存，**释放不了 swap**；且 swap 近满时引擎重启可能直接 bootstrap 失败（DEF-320）。唯一解＝**重启系统**（本次 05:52 已做，swap 10.44GB→0） |
| 引擎内存准入拒绝（denied）持续攀升 | **部分**（治标） | denied 是 swap 耗尽的**下游症状**；判据新增 swap 项把根因提前暴露，但不自动执行系统重启（守护无权杀掉用户会话与在飞工作） |

## 3. 升级后的决策模型（两个判据 + 三道安全阀）

```
(A) 清场 recycle   ：上轮 batch=True → 本轮 batch=False  且  累计 denied > 500
                    ⇒ 重启一次（覆盖「批跑收官带残留」）
(B) 持续劣化 degraded_now：滚动 denied 速率 > 300/h  或  headroom < 8GB  或  TTFT p95 > 60s
                    且 batch=False ⇒ 重启（速率口径，不用累计量）
安全阀：冷却 900s ｜ 最大尝试 3 次 ｜ 失败计入退避（成功则归零）
```

- **swap 判据**（新增，只告警不自动动作）：`swap > 6144MB` → WARN；`swap ≥ 90%` → CRIT，
  文案直指「引擎重启救不了，需重启系统」；建议项同步给出「择机重启系统」。
- **启用**：AUTO_RESTART=1 经 launchd 作业 `com.llama-defender.monitor` 的
  `EnvironmentVariables` 注入（此前恒 0＝功能从未生效）。
- 决策与闸门逻辑落在 `tools/monitor_window.py` 纯函数层
  （`recycle_needed` / `degraded_now` / `restart_allowed` / `swap_alert`），
  单测覆盖 19 例。

## 4. 遗留（明确不做）

- **不自动重启系统**：会终止用户会话、IDE/agent 会话与在飞工作——属用户决策，只做告警+建议。
- **不在批跑中途重启**：红线 1（批期禁重启）。批跑期的劣化只告警，收官后一次性清场。
- **不自动改代理行为类参数**（压缩档/epoch 阈值等）：那属 J6 行为类，需预注册判据与空窗授权。
