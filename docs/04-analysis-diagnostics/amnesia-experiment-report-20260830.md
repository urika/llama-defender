## E2 详解（主判定）

### 配对方法

对每个 ILE 轮（`ifc.ile=true`），取 ILE 前 ≤2 轮内最近的探针 H_BE 为基线、ILE 后 ≤2 轮内最近的探针为响应，计算 ΔH = 响应−基线；与该轮的信息损失量（`dropped_chars + shrunk_chars`）做 Spearman 相关。

### 结果

```
可配对 ILE 事件: 96（来自 14 会话）
Spearman ρ = −0.0398
会话级置换检验 p = 0.6962（5000 次置换）
```

**解释**：损失量与熵变化之间**无相关**。43/96 正相关 vs 53/96 负相关——与随机无异。ΔH 均值 −0.035（几乎为零），中位 −0.020。

### 敏感性检查

- 正相关方向（损失↑→熵↑）比例：43/96 = 45%（硬币水平）
- 信号强度：远低于任何可检测阈值
- **结论对阈值选择不敏感**：在 ρ=0.3/0.4/0.5 任何门槛下均不通过

### 效应量门槛的折扣验证

| 来源 | 效应量 | 环境差异 |
|---|---|---|
| MMPO 论文 | r=−0.684 | 训练任务、全精度、RL 优化后的记忆策略 |
| 本实验 | ρ=−0.040 | text 任务族、4-bit 量化、无训练 |
| 折扣 | **~0×（不迁移）** | 信号在该族不存在或低于本实验检出限 |

## 预注册的"双无"裁决路径

协议 §1 预注册：*"E2/E3 均无 → 只允许'信号无效 / 该族不敏感'两种解释，裁决方式为 code 任务族补批"*

**当前状态**：E2 明确无信号 / E3 方向正确但不显著——**部分触发裁决条款**。两种待判别解释：

1. **信号无效**：信念熵探针在本系统条件下（4-bit 量化 + 本地模型 + 锚定问题措辞）根本测不到信息损失效应
2. **text 族不敏感**：文本生成/处理任务的信息冗余度高（任务说明可重推导），截断损失不损伤信念；coding 任务（代码结构依赖性强）可能不同

**裁决方式**：code 任务族（SWE-bench 式）补批同协议实验。

## §6 轨迹级补充分析（论文原始口径，事后分层标注）

> **性质**：预注册外探索性分析（事件级 E2 FAIL 后追加，明确分层为探索性，不修改 E2 确证性判定结论）。动机：E2 测的是事件级（单次 ILE → 局部 ΔH），论文原始主张是轨迹级（整条轨迹的 ΔH 趋势 × 最终成败）——两者不是同一假设。

### 三层分析结果

| 层次 | 假设 | 效应量 | 判读 |
|---|---|---|---|
| **事件级**（E2 原判定） | 单次 ILE 损失量 × 该次 ΔH | ρ = −0.040（p=0.70，n=96） | 无信号——单次效应 < 探针噪声 |
| **会话级剂量效应** | ILE 累积次数 × 轨迹 ΔH 趋势 | **ρ = +0.335**（n=13 治疗会话） | **累积效应存在**——截断越多的会话熵越上升 |
| **轨迹级**（论文口径） | 轨迹 ΔH（前半→后半）× 最终成败 | 对照 r_pb = **+0.257**（n=23）；治疗 r_pb = +0.140（n=13） | **方向与论文一致**，但量级折损 ~62% |

### 轨迹级详细数据

**对照批（keep=600, ILE=0, 健康域）**：

```
resolved ΔH 均值: −0.0753 (n=17)  ← 熵下降=信念清晰化
failed   ΔH 均值: +0.0287 (n=6)   ← 熵上升=信念恶化
点二列相关 r_pb = 0.2570
```

**治疗批（keep=12, ILE=130, 截断域）**：

```
resolved ΔH 均值: +0.0041 (n=9)   ← 几乎平坦
failed   ΔH 均值: +0.0558 (n=4)   ← 轻微上升
点二列相关 r_pb = 0.1402, 95% CI [−0.445, 0.642]
```

**合并**: r_pb = 0.2197 (n=36)

### 关键发现：信噪比的层次结构

事件级 ρ≈0 + 会话级 ρ=0.335 + 轨迹级 r_pb=0.14-0.26 的组合意味着：

- **单次信息损失的效应量低于探针测量噪声**（事件级被衰减到不可测）
- **多次截断的累积效应超过噪声底**（会话级可测）
- 这不是"信号不存在"，而是**信噪比在事件级不够、在会话/轨迹级刚好够**

### 对 MMPO 论文主张的判定

| 论文主张 | 我们的证据 | 结论 |
|---|---|---|
| ΔH_BE 与最终精度强相关 (r=−0.684) | 轨迹级 r_pb = 0.14-0.26（同方向，折损 ~62%） | **部分复制** |
| 成功轨迹熵持续下降 | 对照 resolved 均值 −0.075 ✓ | **支持** |
| 失败轨迹熵停滞/上升 | 对照 failed 均值 +0.029 ✓ | **支持**（幅度小） |
| 损失→熵因果链 | 事件级无 / 会话级 ρ=0.335 | **累积效应存在，非单事件** |

### 对 E2 解释与 R9.3 门控的修正

| 原判定 | 修正后 |
|---|---|
| ~~信号无效~~ | **事件级信噪比不足；累积效应存在（ρ=0.335）** |
| ~~门控永不上线~~ | **单事件门控不上线；累积趋势门控待 B1 噪声底评估后重定** |

门控触发条件的修正方向：从"ILE 后单次熵跳升"改为"会话熵趋势持续上升 N 轮"——与协议 §7.5 的"趋势化触发"设计一致，但需要 B1 噪声底数据确定趋势窗长与阈值。

### 与 code 任务族补批的衔接

轨迹级方向已支持论文（r_pb>0），code 族补批的目标从"裁决信号有无"调整为"裁决效应量能否达到门控阈值（≥0.4）"——text 族 0.14-0.26，若 code 族达 0.4+，则证明族依赖性并解锁 code 场景的门控。

## 阴性结果的科学价值（修订后）

这是首个受控实验表明：**在 text 生成任务族上，信念熵对单次上下文截断的响应低于探针噪声底，但累积效应在轨迹/会话层可见**。这一结果：

1. 对 MMPO 论文的 r=−0.684 构成**域外不复制证据**——该效应不能无条件推广到 text 任务族 + 本地量化模型
2. 精确化了迁移条件：论文效应可能仅在（a）训练后的记忆策略下（b）全精度模型（c）其训练任务族成立
3. 为后续研究指明方向：需用 code 任务族裁决"信号无效 vs 族不敏感"
