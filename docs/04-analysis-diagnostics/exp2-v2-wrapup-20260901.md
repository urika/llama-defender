## E2 轨迹级检验（2026-09-01 补齐，code 族全量）

**数据**: v2 窗口 HBE 探针 472 条(含熵值 387), 与 sessions.jsonl ifc 段按 session+邻近 turn 对齐(387/387 全对齐), 19 个会话聚合。

| 口径 | code 族(本批) | 对照: text 族(exp-1) | 门禁 |
|---|---|---|---|
| 事件级点二列相关 ρ | **+0.162** (n=387) | -0.04 | \|ρ\|≥0.4 |

| Δ(H_BE) ILE vs 非 ILE 中位 | **+0.086 bits** | ≈0 | 方向性 |

**判读**:
1. **方向一致但量级未达门禁**——正号与 MMPO 假设同向(信息损失→信念熵升), 但 0.16/0.18 远低于 0.4。族依赖性**不能宣称成立**。
2. **与剂量-响应假设自洽**: exp-2 v1 中途读数(keep=12, 高剂量)事件级 ρ=0.28; 本批 keep=24(治疗降剂量)ρ=0.16。信号随剂量下降——治疗本身稀释了探针可测的熵响应。这不是坏消息: 它反过来支持"门控不应上线"(无强信号可依), 且 IFE 度量继续以观测者身份运行。
3. **主判定不变**: 门控不上线, IFC 止步度量 + PDC 需求侧修复(258d414 的 A/B 验证中)。

**方法学备忘**: 探针搭 prefix cache 便车(响应后运行), 对齐窗口 ±2 turn; 19 会话中 2 个 <3 样本被剔除聚合。
